## 服务流程 / How I Work

1. **需求确认 Requirement intake**：明确产品规格、质量标准、目标数量、目的国准入要求与预算区间。
2. **长名单 Long-list**：通过国内产业带、国内 B2B 平台与工厂网络初步匹配候选供应商。
3. **资质初筛 Document screening**：核验营业执照、经营范围、生产/经营许可、产品注册证、ISO/CE/FDA 等认证的原件与可查性。
4. **比价与样品 Quotation & samples**：多供应商报价比对、样品确认与技术参数核对。
5. **验厂与背景核实 Audit coordination**：安排实地走访或第三方验厂机构（如 SGS、TÜV、BV 类），核验产能、设备、质检体系与交易/纠纷记录。
6. **尽调报告 Due-diligence memo**：输出候选供应商对比表、风险点与推荐结论，供客户决策。
7. **订单跟进 Order follow-up**：合同条款协助、生产进度跟踪、验货协调与发货衔接。
